This is the scenario companion to [the completion plan](80-completion-plan.md#62-sub-9-khz-work-package) and the evidence in [propagation](10-sub9khz-propagation.md), [antenna/link](11-sub9khz-antennas-links-and-practice.md), and [noise](12-sub9khz-noise.md). These are bounded engineering specifications for a later native harness; the route, transfer solver and calibrated receiver inputs named below remain prerequisites, not measured joint distributions or claims of receiver qualification. Inputs below are fixed values or explicit ranges; do not sample a natural occurrence distribution where the cited evidence does not provide one.

## Scenario A — quiet, stable reference (forecast/control)

- Hold the path in a night-time interval with fixed endpoints and no terminator crossing during the 96-minute bit. Use the h′ = 87 km, β = 0.3 km⁻¹ reference profile and propagation model without adding a fading distribution. Keep antenna capacitance and loss fixed at the reference values above; impose zero weather detuning and a frequency-disciplined carrier.
- Noise is a stationary baseline sensitivity, not a claimed natural distribution: run separate fixed PSD cases of 20 fT/√Hz and 50 fT/√Hz; within each, compare Gaussian input with a source-informed impulsive waveform only if calibrated broadband input and receiver transfer are available. Set coherent phase to constant after removing deterministic propagation and antenna phase. Do not draw Vd or PSD samples from a fitted marginal and call the result a field probability.
- Observable outputs: delivered DATA/Helper input PSD and spectrum; post-filter SNR/C/N0; phase residual and coherent loss over the 96-minute interval; receiver detection/erasure decisions; completion time after two scored quiet slots; peak/live DSP memory. Public outputs exclude the hidden message endpoint and truth values.
- Validation: match the input field and antenna transfer against injected calibration signals at the receiver port; independently verify the analytic 1-Mm path calculation and noise-unit conversion. This verifies implementation arithmetic only; no sub-9 kHz matched-field holdout is currently identified.

## Scenario B — coupled day/night transition with regional lightning noise (adverse, conditioned)

- Override the midnight origin: start three hours before the chosen path-midpoint sunrise and schedule a native DATA slot so its 96-minute active bit overlaps dawn. Run through that slot, both subsequent scored quiet slots and a declared post-completion observation; six hours alone may be insufficient. Drive the path profile from solar zenith angle along the path; use a single selected profile trajectory and preserve mode/phase memory. Apply any amplitude/phase steps only from the selected propagation solver or a measured time series. Chapter 10 reports measured 8.3-kHz phase excursions and model ranges, but no controlled-source 1-Mm time series sufficient to calibrate a probability law.
- Tie noise changes to local time and an explicit lightning driver. The source-informed conditioning is: lightning within about 3,500 km can dominate a Suizhou 3–30 kHz noise observation; seasonal changes up to 10 dB were observed there (Gu et al. 2021). For bounded sensitivity, hold the baseline at 50 fT/√Hz and apply a deterministic +10 dB change in noise power spectral density during one declared 30-minute stress interval (equivalent amplitude density 158 fT/√Hz); separately test unchanged PSD. This +10 dB is an adversarial conditioning choice inspired by the reported seasonal magnitude, not a measured local-storm jump or joint distribution. If actual matched lightning/noise data are later obtained, replace the step with those measured timestamps and preserve the measured broadband waveform.
- Reuveni et al.'s 4/7.5 kHz Vd evidence is from 75-Hz one-minute records sampled every 15 minutes at one Negev site. It does not define this 0.06-Hz in-channel residual. Therefore evaluate a pair of alternatives: (i) linear colored noise filtered to the measured PSD; (ii) broadband sferic bursts passed through the actual antenna/receiver chain, with impulses and blanker behavior enabled only when the waveform/arrival sequence is source-backed. Compare an independent-noise null with a shared-time/state case in which solar zenith or geomagnetic state is common to wanted-path propagation and receiver-local noise level. Keep lightning source bearings/distances and their propagation to the receiver distinct from the wanted transmitter path; do not make noise and wanted signal share one fade transfer. Assign no natural joint probability without matched data.
- Add a separate antenna detuning discriminator, not a silently coincident natural event: change capacitance by ±0.1% over 10 minutes and return over 30 minutes. Compute phase/amplitude from the stated loaded-Q transfer function; these durations are harness stress choices because measured wind-driven capacitance spectra for this antenna class were not found. Keep this state independent of the propagation/noise branch unless measured weather data justify coupling.
- Observable outputs: time-indexed source truth for solar angle, path transfer, local lightning driver, PSD/APD, antenna resonance and wanted energy removed by nonlinear processing; public receiver decisions, tracking/Helper state, phase error, blanked fraction, quiet-slot completion and resource use. Report distributions across fixed seeds separately from uncertainty in source parameters.
- Validation: compare each single mechanism against the relevant source quantity (phase trend/attenuation; calibrated PSD/Vd/waveform; antenna impedance/resonance). Reuveni is a 75-Hz statistical check, not a 0.06-Hz holdout; Gu is regional and its linked data require a separate access/format review. No scenario-level empirical pass is currently possible. Before running, choose and record exact endpoint coordinates and dates/time scale, ground-conductivity profile, receiver field component/orientation and transfer function, plus an identified waveguide solver with normalization and an explicit solar-angle-to-h′/β trajectory. The current 1-Mm, midlatitude description does not fix these inputs. Preserve modal E/H relations from that solver; do not apply a plane-wave 377-ohm conversion to an arbitrary near or modal field.

## Scenario C — detection failure / physical outage (explicit stress, not a natural worst case)

- Preserve the same antenna, path, signal and continuous state as Scenario B. Use two separate stresses: a 30-minute below-threshold interval, and a slot-aligned fade that covers the full scoring apertures of at least two consecutive public quiet decisions while transmission continues. Determine the actual interval from the configured calendar and tails; the approximately 6,750–6,767 s slot spacing in row 1 makes 30 minutes insufficient for this longer test. Set the wanted received field below the calibrated receiver-detection threshold, or use a documented measured fade if available. Keep noise present at the adverse PSD level and retain any existing filter, decoder and channel memory through the outage and recovery.
- Mark the complete fade as an evaluator-controlled stress. Do not describe it as an observed sub-9 kHz outage rate, draw it from an unobserved distribution, or substitute transport EOF, cancellation, quota exhaustion or a known simulation endpoint for successful completion. On recovery, record whether each interior slot was classified as DATA, null, or erasure and preserve the actual codec and ordered-slot behavior. Completion follows the two-scored-quiet rule; a sufficiently deep fade during continued transmission can be observationally indistinguishable from physical silence.
- Observable outputs: whether DATA/Helper acquisition continues to be attempted; missed/erased slots; premature completion and accepted-truncation counts, with any integrity rejection; reacquisition latency; final completion result; state continuity; memory and CPU backlog. Keep outage interval and message-end truth hidden from the receiver.
- Validation: inject an independent below-threshold waveform, record the actual quiet, erasure, or false-DATA outcomes, then restore signal and evaluate ordered reacquisition and completion. A zero premature-completion rate is not guaranteed when two quiet decisions are observationally indistinguishable from an actual transmission end. This is a deterministic contract test, not evidence of natural outage probability.

## Evidence and limits

[Gu et al. (2021)](https://doi.org/10.1029/2020JA029101) report measurements from Suizhou, China, February 2016–February 2019, across 3–30 kHz: seasonal differences up to 10 dB and a dominant contribution from lightning within about 3,500 km. The sub-9 kHz pass read the abstract and identified but did not analyze the linked dataset; a separate pass accessed the publisher full text and records its instrument and time-resolution limits in [50](50-noise-and-interference-mf-hf.md). [Reuveni et al. (2011)](https://www.ursi.org/proceedings/procGA11/ursi/EP1-8.pdf) is a full proceedings paper: 386 days at Sde-Boker, one-minute records every 15 minutes, Vd at 4, 7.5, 10 and 26 kHz, 75 Hz bandwidth. Neither source provides antenna-specific field calibration, a sub-9-kHz long-aperture outage distribution, or the joint process needed to label Scenarios A–C naturally likely. Keep all scenario outcomes forecast-only until matched measurements and independent holdouts are available.

For the 1 mW, 1 Mm modeled night field of 523 nV/m in chapter 11, 2 mW gives about 740 nV/m by square-root power scaling. Under a plane-wave E=cB approximation only, that is 2.47 fT and yields approximately −18.2 and −26.1 dB-Hz against 20 and 50 fT/√Hz, before receiver self-noise. The separate chapter-11 −11.5 dB-Hz example and chapter-12 11 fT/√Hz plotted baseline use different noise-figure readings; they are not the same fixed case.

## Bounded complex-field reference

For a concrete independent physical-model reference, use a version-pinned [LongwaveModePropagator example/interface](https://fgasdia.github.io/LongwaveModePropagator.jl/stable/generated/basic/) offline to tabulate vertical electric-field amplitude and phase at 8,270 Hz and the calculated great-circle range above. Use its homogeneous vertical-dipole waveguide, `Ground(22, 0.003)`, `BField(50e-6, 65° in radians, 0)`, the documented electron collision profile and Wait–Spies profile. In the package, dip is measured downward from horizontal and azimuth from the propagation direction; these values are illustrative, not a measured geomagnetic model. Use h′=87 km and β=0.30 km⁻¹ for the stationary reference. For a deterministic transition sensitivity let u=(t−t_sunrise)/1800 s, h′(t)=80.5−6.5 tanh(u) km and β(t)=0.40+0.10 tanh(u) km⁻¹, uniformly along the path; compute complex field on a declared 60 s grid, unwrap phase and interpolate with a convergence check. This is a synthetic smooth profile, not an observed sunrise event or a qualified probability law.

The public sampler documents electric components only, so this reference establishes Ez, not the magnetic-field pickup in the other branch. Use a separately calibrated electric receiver/noise reference for an absolute electric-field example; do not derive local H from Ez by a plane-wave identity. Specify transmitter power using the solver’s documented convention and calibrate its radiated power/antenna normalization before making absolute link claims; using ratios E(t)/E(reference) only checks relative transfer. Record package version, solver settings and generated complex table. The Julia model is an offline reference/oracle, not an operating modem stage or a replacement for native DSP; a future in-process native renderer can use a validated table or compatible implementation.
