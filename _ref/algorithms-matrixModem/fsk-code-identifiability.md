# What survives the loss of FSK tones

The short block can identify a payload even when individual coded bytes are ambiguous. Its tolerance of lost tones depends on which symbols survive, their usable energy, and how long the path stays unusable. This audit concerns the fixed-calendar short-block format in the [FSK specification](../../_appraisal/matrixModem-FSK.md#block-coding-and-calendar). The calculations concern the former specification's alphabet and placement proposal, preserved with its original numbering in the [dated design study, §§5–10](fsk-design-study.md#5-alphabet-and-keyed-placement). It uses noiseless labels to find ambiguities that greater transmit power cannot resolve. The exact calculations and a separate check against the existing C++ generator are [reproducible locally](../../_appraisal/algorithms-matrixModem/code-identifiability/README.md).

## What two 16-position observations convey

An 8-bit code symbol is internal to the encoder. With `P` positions, one tone conveys at most `log₂ P` bits in its position. The repeat floor `ceil(8/log₂ P)` gives enough *possible tuples* for 256 values. Two independent balanced 16-way maps may nevertheless assign several bytes to the same ordered pair. For any particular pair of positions the first coordinate selects 16 of the 256 bytes. The second coordinate selects 16 uniformly without replacement. The chance that the two sets are disjoint equals `C(240,16)/C(256,16)`. Hence the expected number of distinct tuples equals

```text
256 × [1 − C(240,16)/C(256,16)] = 167.770328.
```

For equiprobable bytes, the optimal decoder gets one byte right in each occupied tuple class. Its average noiseless error is 34.4647%. This calculation averages over independent uniform balanced maps. One actual schedule has an integer number of occupied tuples. The per-tone common phase carries no extra data here. Two identical balanced partitions, even with different position names, give a simple worst case with only 16 distinct tuples. The prototype uses fresh shuffles and takes the lower position bits on each repetition. [Existing placement generator](../../_appraisal/algorithms-matrixModem/sub9-fsk-rate/coherent_block_mc.cpp)

For a fixed erasure footprint, two messages can be distinguished exactly when their surviving position vectors differ. For uniform messages on a noiseless channel, let `D` count distinct vectors across all `2^k` messages. Even an ideal decoder has minimum error `1 − D/2^k`. When the surviving labels recover complete code bytes, stack their binary generator rows. The resulting rank `r` gives `D = 2^r` exactly. With arbitrary balanced partitions, full rank of those outer rows is necessary and may be insufficient after placement. An injective coordinate per retained byte, or an injective tuple of coordinates for it, restores the rank test for those bytes. Known XOR masks leave rank unchanged.

For the idealized draft ensemble one can also bound message ambiguity cheaply. Assume independently uniform binary rows per symbol and independently uniform balanced maps per tone, with erasures fixed independently of those draws. For a particular pair of different payloads, their generated bytes coincide with probability 1/256. When their bytes differ, a single balanced map gives the same position with probability `c = (256/P − 1)/255`. For `r_j` surviving repeats of symbol `j` the pair-match probability is `q_j = [1 + 255 c^(r_j)] / 256`, with `q_j = 1` if all its repeats were erased. The expected number of rival messages indistinguishable from a specified message equals `(2^k − 1) × ∏q_j`. This also upper-bounds the probability of at least one rival, and can be uninformative when it exceeds one.

At 24 bits, 16 positions and two surviving tones for every one of 32 symbols, the expected rival count is **8.94 × 10⁻⁶²**. The byte collisions above give little reason by themselves to change this full-block format. With only six surviving tones spent on six distinct symbols, the count is 1.00. The same six observations spent on three twice-repeated symbols give 6.67. Greater power cannot create more independent labels. These are ensemble expectations for noiseless positions, with no antenna model, noise threshold or false-presence decision.

For four fixed seeds of the actual 10-bit experimental generator all 1,024 payloads were distinct through every tested 16-hop and 28-hop contiguous loss in a 32-hop block (two adjacent tones per hop). Enumeration of all 523,776 pairs per fixture gives minimum hop distances of 28, 27, 28 and 28 respectively. Thus each fixture survives **any 26** known noiseless hop erasures. Seed 2 admits an ambiguous pair for some set of 27. The shortest contiguous erasure that causes an ambiguity is exactly 30 hops for every fixture. With 31 contiguous hops erased, only 249–254 distinct messages remained across the fixtures. On seed 2 two surviving tones of symbol 0 gave 107 classes. One surviving tone from each of symbols 0 and 1 gave 226. The pure schedule exercise imposes this hop grouping on the 64 existing tone positions. It establishes the number of noiseless possibilities on these fixtures. Partial interference and weak-signal error can dominate long before exact ambiguity appears. [Fixed-schedule results](../../_appraisal/algorithms-matrixModem/code-identifiability/fixed_schedule.txt)

If independent recovery of each coded byte becomes a requirement, two 16-way maps can send complementary four-bit groups of a single permuted byte, with the positions in each tone independently relabeled. All 256 position pairs then occur once. This retains two transmissions and the per-symbol table shape. It couples placements across the two tones and changes codeword distances. Adoption would require comparing message errors with the same signal energy, noise, erasure locations and receiver. The present payload objective can instead retain independent maps and qualify the actual scheduled code. Testing all 1,024 messages is inexpensive at 10 bits. For larger payloads, rank tests on full bytes and the ensemble bound cover specified limits without running all pairs.

## Erasure count and duration

The earlier 6 dB margin example uses a tolerated lost fraction of 0.77 and independently erases each hop with probability 1/2. A block of 32 equally weighted hops exceeds that budget when 25 or more vanish. The exact probability is 0.001051201. It falls to 0.000659364 at 33 hops. With *exactly* 16 out of 32 erased the loss in usable time is 3.01 dB under equal exposure. These three results address different events. The tolerated fraction itself came from an ideal random-erasure calculation for a specific choice of branch SNR, diversity, error criterion and known erasures. The prior program selected a reported minimum hop count by testing that count and the next eight, since the discrete tail can rise as the hop count increases. [Prior hop calculation](../../_appraisal/algorithms-matrixModem/fsk-lattice/results/lattice_receiver_section16.md) · [Original erasure assumptions](Fable-5.2/reviews/review-coding-interleaving.md#55-from-margin-to-erased-fraction)

Consider a stationary symmetric two-state channel. A good hop arrives perfectly and a bad hop carries no information. A transition between states occurs with probability `s` at each hop boundary. Every choice of `s` has the same 50% mean loss, with mean bad run `1/s`. The probability that more than 77% of a 32-hop block disappears is 0.001051 for a mean run of 2 hops (independent losses), 0.037618 for 4 hops and 0.159272 for 10 hops. These numbers follow by propagating the joint distribution of the loss count and current state. They describe the input to a decoder. The exact probability of a completely erased block is `0.5(1−s)^31`. For ten-hop mean runs this is **1.9076%**. A uniformly selected payload must then incur error or rejection with probability at least `0.019076 × (1 − 2⁻ᵏ)`, even at arbitrarily high surviving SNR. This constructed finite channel already rules out a universal 10⁻³ guarantee. Its transition probabilities do not represent measured HF conditions. Interleaving can change which symbols are hit by a partial outage. Every interleaver loses the whole block during a block-long outage. ## Implications for receiver evidence

- The earlier 0.2 dB gap at 10 bits and 0.3–0.7 dB at 20 bits compares particular small random banks with an orthogonal reference under ideal Rayleigh energy observations. The earlier calculation also measured both near-unity repetition efficiency for weak looks and **0.425** at 32 looks, 64 labels and 0 dB per look. Efficiency there means information from repeating one symbol divided by information from independent symbols on the same number of looks. These results explain where repetition is attractive and where it saturates. They do not give a loss figure for the specified interleaver, binary rows, real placement, search and clipped scores together. Exhaustive search maximizes the score supplied to it. Calling that score maximum likelihood requires the conditional likelihood of the retained observations under a stated model. [Prior code and repetition results](../../_appraisal/algorithms-matrixModem/short-message-energy/results/codebook_mc.md)
- Report the erased physical hops, the surviving repeats per symbol, the distribution of loss durations, and exposed transmitted energy alongside payload errors and missed presence. For qualification, check that full labels give rank `k` and test the actual projected code on the stated adverse erasure footprints. In a specified loss family, deterministic noiseless recovery requires distinct restricted codewords for *each* allowed footprint. Bounds for linear block codes on the q-ary erasure channel depend on the actual code or ensemble. The general balanced placement here can be nonlinear, so the linear-code bounds need an applicable representation. [Liva, Paolini and Chiani (2013)](https://doi.org/10.1109/TCOMM.2013.032013.120504)
- A burst guarantee requires an envelope such as a maximum contiguous run in a finite window. Kas Hanna et al. constructed codes for bounded burst and arbitrary erasures under a decoding-delay constraint. Huang et al. (2025 preprint) instead analyzed random linear streaming codes over stationary Markov symbol erasures and found that the performance ranking depends on the loss model. Both works involve different codes and packet abstractions. The applicable lesson for Matrix is to specify the erasure pattern or state-transition law before assigning a robustness guarantee. [Kas Hanna et al. (2023)](https://arxiv.org/abs/2302.08644) · [Huang et al. (2025), §§I and III](https://arxiv.org/abs/2509.01894)
