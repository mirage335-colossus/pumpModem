# Private owner census schema 1

Authoritative field producer: `owner_census_probe.hpp`. Baseline a9b2d95a; no production qualification. One original default-provider simulation fixture; natural origin is not pinned. No paired overhead or fixed-work inference. Root supplies strict existing trace footer/external-seal validation. This document adds constraints, not fictional producer fields.

Every census event has integer `sequence` and numeric `steady` from existing audio_trace, plus integer `census=1`. Every f.add bool is numeric 0 or 1 in this build (accept JSON booleans only if explicitly normalized). All counters/coordinates are nonnegative integers; seconds/Hz/scores/absence are finite numeric values unless audio_trace emits null (null in a required geometric/timing field makes that inference unavailable). Strings have their literal quoted meaning. No track/owner payload bits, keys or secrets are recorded; key_tag is a bounded receiver-bank MAC identifier.

Exactly one `owner_census_begin`, candidate and terminal summary are required. No census record may occur after summary. Order: begin, candidate, then per-owner pattern_state + tracks + owner. Join records by owner integer, not event order or GUI row. Owner ordinals must cover 0..summary.owners-1, exactly one owner and one pattern_state each. Track ordinals per owner cover 0..pattern_state.track_retained-1. Pattern_state may precede its owner.

## Exact conditional fields

The producer is authoritative for the full required field list in each event. These are its conditional branches:

* begin: observed_epoch is present iff observed_epoch_known=1. All other begin fields are unconditional. journal_valid=0 means journal coordinates are not observations and cannot be interpreted. reason may be clipped to512 characters.
* candidate: valid=0 means epoch/family/tag/profile are contextual defaults, not a claimed failed constructed candidate. config_known/search_known/allocation_known distinguish preparation stages. start_seconds iff start_known=1, allocation iff allocation_known=1. All other emitted fields exist unconditionally but are meaningful only after their corresponding known flag. key_tag contains32 bytes of bounded storage (zero-filled beyond key_tag_size); compare only the first key_tag_size bytes. key_tag_size>32 is explicitly truncated. Candidate has no modem/track state.
* pattern_state: owner, available and backend always. available=0 has no other required fields; fallback backend is `pattern_correlator_fallback`, or missing inspector backend `no_pattern_receiver_inspection`. available=1 has all fields in producer except start_seconds iff start_known=1. track_total and track_retained must be integers and track_retained=min(16,track_total).
* track: all producer fields unconditional except needed_end_bin and input_ready, which exist iff needed_end_overflow=0. radius_known=0 makes the readiness envelope unavailable. pending_count_valid=0 forbids interpreting pending_symbols. stream_first_sample/end/confirmed_end are receiver-local input sample coordinates; add the matching owner's sample_origin for Bank coordinates. next/anchor/needed/available are receiver bin coordinates; bin_samples comes from pattern_state. `lookahead_assumption` is exactly `non-final continuation radius`, not a claim that the scheduler executed that fit. An admitted track, drained confirmed=0, pending_gap or nonzero pending weak symbols is not by itself a retirement defect. absence must be interpreted against actual confirmed events and fully scored fit readiness.
* owner: local_ingress iff ingress_valid=1, frontier iff frontier_known=1. For journal_match=0 no decision_retire/expiry_known/expired/decision_frontier_queried/decision_frontier_known/decision_frontier exist. For journal_match=1, all those flags exist; expired iff expiry_known=1; decision_frontier iff decision_frontier_known=1. decision_reason=`not_observed_in_latest_refresh` means exactly unavailable, not proof of a new owner. Actual decision coordinates are begin.journal_revision/sample/now; they are not current snapshot decisions. Current query_complete=0 invalidates synchronized/initial_search_complete/frontier interpretation. Profile fields describe receiver.options.modem; epoch is separately authoritative. Explicit timestamp is the input Options value. Symbol/prefix seconds reconstruct original expiry terms but do not replace actual decision journal.
* summary: thread_cpu_seconds iff cpu_valid=1. All other fields unconditional. rows_before_summary is the number of attempted census events before summary and must equal count(census events)-1 after full trace validation. `pattern_states` counts inspector invocations, not synthesized unavailable records. `track_total` sums available PatternReceiver internal track totals only; fallback track population is unknown. `wall_seconds` and CPU describe one synchronous capture subset before summary emission, exclude journal maintenance, marker/filter checks, summary and all other process work. Four explicit clock attempts plus trace's per-event steady clocks; no whole-run overhead estimate.

## Completeness and equalities

For full intended ordinary-PatternReceiver census inference require: marker=1, schema=1, summary limited=0, probe_errors=0, fallback_unavailable=0, journal_overflow=0, cpu_valid=1, all states available=1 and no track needed_end_overflow/radius failure or tag truncation. Reader must preserve partial findings but mark incomplete rather than invent state when any condition fails. Track cap or owner cap never silently passes.

When complete:

* begin.resident = summary.owner_total = summary.owners = number(owner events) = number(pattern_state events) = summary.pattern_states.
* sum(pattern_state.track_total) = sum(pattern_state.track_retained) = number(track events) = summary.track_total = summary.tracks.
* summary.rows_before_summary = 2 + 2*summary.owners + summary.tracks.
* begin.admissions - begin.retirements = begin.resident where the retained original Bank counters obey that invariant; report disagreement, never repair it.
* begin.journal_retained=min(128,begin.journal_total); overflow iff journal_total>128. Journal may be absent in initial admission or unmatched for owners added after the latest refresh: this does not make current internal track census incomplete, but prevents explaining retirement decisions for those owners. Report exact matched/unmatched counts and coordinates.
* For each journal match, journal revision equals begin.revision; stable join used producer-side is revision+point_consumer+epoch+origin+family. Consumer identities are monotonic in a Bank; no pointers are joined. A retained owner reporting decision_retire=1 is suspicious and must be reported, not ignored.
* bank sample - sample_origin = owner.local_ingress when valid. Pattern input_samples and delayed frontier are independent observed coordinates; do not force them equal to ingress or erase a gap.

Original exact errors and standard source/seal identity remain required. A successful diagnostic process may still contain the original application assertion failure: root workflow must retain its exit/stdout/stderr and report it, not reclassify it as application success.
