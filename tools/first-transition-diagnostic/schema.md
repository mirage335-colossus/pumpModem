# First-transition census, schema 1

Authoritative producer: `first_transition_probe.hpp`, plus the three exact transforms in `prepare.py`. `schema-field-inventory.json` lists actual event variants, field names and C++ expressions (not a runtime specimen). Required/conditional semantics below govern interpretation. No runtime has executed this producer.

## Invocation and closure

`python3 prepare.py --source <clean e257 archive checkout> --output <evidence directory>` prepares only the supplied checkout. It requires exact preimages. Marker `DATAPUMP_FIRST_TRANSITION_CENSUS=1` enables the observer/filter; unset/0 is inert. Invalid other values disable observation and must be rejected by launcher metadata. Run the existing `test_live --simulation-media-clock-trace <explicit trace path>`. Keep its original exit/assertion/deadline result, stdout/stderr, whole-child CPU/wall, source/cache/compiler/binary provenance and strict trace footer/external closure. This is a single natural-origin diagnostic, not qualification or a matched overhead comparison.

Every capture event has `schema` (integer 1), `capture` (positive integer), plus the existing trace `sequence`/`steady`. At most two captures process-wide: first successful constructor fallback, first false-to-true bank coverage condition. A successful fallback may occur in another case/bank before the limit. Never join solely by ordinal/case: use capture + bank_identity + revision + sample + case_sequence. bank_identity is the receiver allocation-account object, stable through Bank move construction/assignment. Bank stack/object address is recorded separately and is NOT a logical join key. Addresses are diagnostic identifiers within this process only. Case code and event sequence are atomically captured together. `case=unknown_external_join_required` remains unknown.

## Event contract

* `first_transition_begin`: one per capture. Integer byte/count/coordinate fields; booleans for knownness/matches; clock coordinates numeric. Records bank stored/recomputed bytes, actual allocator/vector/pool storage, bank budget and configured DSP budget. Shared pool active bytes explicitly nonadditive. Candidate is excluded from resident accounting unless replacement already occupies a resident slot. `stored_matches_recomputed=false` is **not automatically corruption**: at a mid-feed transition the original ledger can still contain `pending_accounted_bytes`, while `pending_actual_bytes` is current. Do not force a zero delta or silently repair it. Full reconciliation must explain that difference and any active storage loan. `pending_*` extra fields exist only when pending_accounted_known. Last trim describes ONE peer call, not the aggregate reclaim. `last_reclaim_*` records the actual most recent aggregate call, with stable bank_identity+revision match flag. Neither implies that every optional allocation was released.
* `first_transition_candidate`: one per capture. `valid/config_known/search_known/allocation_known/constructor_valid/required_known/candidate_modem_known` independently gate fields. Fresh preflight stamp clears prior constructor and required fields. Geometry/key metadata is the original options/profile, not a serialization of every seeded configuration field. `candidate_capacity/control_margin` are known for preflight/constructor stages, unknown at mere preselection; zero defaults are not measurements. R values/core grant are meaningful only when required_known/constructor_valid respectively. native_minimum is the ORIGINAL streaming-eligibility expression without_rows+2*track_limit+2, not a promise to reserve all future retained bit/content growth. `candidate_in_bank` distinguishes constructor replacement from unadmitted new candidate. Public candidate working/reserved/backend/limit flags exist only if candidate_modem_known. Unavailable fallback internals must remain unavailable.
* `first_transition_pattern_state`: one per inspected resident modem, plus at most one unadmitted candidate. Native `available=true` includes input/search geometry, capacities and reservations. Fallback `available=false/backend=pattern_correlator_fallback` has no native internals. This is an expected opaque branch, not a fabricated native state. Integer owner 0..resident-1 joins resident rows; owner 512 denotes extra unadmitted candidate.
* `first_transition_component`: native-only, integer owner/index/size/capacity/element_bytes/capacity_bytes, string component, boolean additive. Capacity bytes equal capacity*element_bytes. Additive components include nested independently owned vector buffers. `native.scoring` capacity is explicitly nonadditive: the application accounting charges scoring_reservation instead. Do not add fixed/cache/budget/reserved charges to component heap sums. Native-other charge is a signed residual from the actual modem accounting, not process RSS.
* `first_transition_optional`: native-only, owner, current source-derived template-cache reclaimable charge; includes_scoring_reservation/reservation_part_nonadditive qualify the estimate. Last continuation is known only for the current constructed Impl identity with a recorded call; stale constructor reuse resets call validity. Continuation fields are conditional on last_continuation_known. The observer does not rerun continuation/scoring. Resident reclaimable sum and unadmitted candidate charge are separate summary fields.
* `first_transition_track`: native-only, at most128 per owner. Original track identity/frequency/phase/stream coordinates, admitted/established/confirmed/pending/absence/end; current available-bin and non-final continuation-radius geometry. Conditional needed_end when no overflow; geometry-known before using radius. `input_ready` alone does NOT prove a continuation could have run: compare recorded last continuation cap and schedule. Absence classification still requires six fully scored seconds; observation changes no policy.
* `first_transition_owner`: exactly one per retained resident inspected, capped512. Integer owner/consumer/epoch/family/origin, key tag string, exact receiver_workspace total and all its source terms: modem/content, presentation accounting, heap score history/ordinal, key/targets, receiver bursts+bits, owned FHSS plan, source family. `owner_component_sum==workspace` and owner_ledger_matches must hold for exact owner accounting. Native component subtotal/other residual are meaningful only for native backend. Retirement match uses stable bank_identity+revision and consumer+epoch+origin+family. If journal does not match, retain unknown; no inference from GUI rows or stale refresh. Expiry only emitted when actually evaluated. Public synchronized/initial_search_complete/frontier are current queries; no diagnostics() or point mutation is called.
* `first_transition_summary`: one terminal summary per complete capture. Integers owners/owner_total/states/tracks/track_total/components/receiver_sum, resident/candidate optional sums; booleans limited/errors(queue_timeout etc), numeric observer CPU/wall. Full resident enumeration requires owners==owner_total, states==owners+(one extra candidate iff emitted), tracks==track_total, no limits/errors/queue timeout. `fallback_private_state_unavailable` counts expected opaque modem state rows; it prevents native-internal completeness claims for those owners but does not invalidate exact public owner totals. Prefix/continuation overflow invalidate their affected proof. `rows_before_summary` equals capture-event row count preceding summary; summary itself is one additional row. If an emit cap/timeout prevents summary, that capture is incomplete. A `first_transition_failure` is always incomplete.
* `first_transition_run_summary`: cumulative process counters at joined Session destructor, inside outer trace Scope. May appear more than once (the suite constructs several Sessions). Capture count must agree with unique captures in the final cumulative row; fallback_captured/limit_captured record hook attempts and alone do not prove full capture. Require terminal summary for each. context_mismatches must be zero for coverage completeness. Invalid marker/no observed first event is not a proof that the underlying event never happens globally.

## PCM input identity

At every successfully committed feed, the probe hashes raw float object bytes in source order after bank.samples advances. Capture hash includes **only committed complete blocks**, never unfed/current uncommitted input. Require committed_pcm_sha256_valid, pcm_little_endian, !prefix_overflow and committed_pcm_samples==committed_pcm_boundary==bank sample. Partition count is successful committed feed calls (including zero-length publication feeds if present); digest covers those exact bytes, independent of partitioning. A skipped unobserved span or discontinuous/missing prefix marks invalid; no invented silence. Prefix context uses source-quota identity+revision and resets at first coordinate0. Diagnostic prefix table is bounded16. Digest is copied/finalized without mutating the ongoing context. A future comparison of a limit raised DURING an uncommitted block additionally needs that triggering block; this digest alone does not establish it.

## Measurement scopes and limits

Observer CPU/wall covers capture entry through resident/native queries/emission and bounded queue waiting, excluding its summary, all pretransition hook/journal/hash/filter cost and writer CPU. Four explicit clock calls are attempted (two steady, two thread CPU); cpu_valid must hold before numeric CPU interpretation. No calling-thread=sum-workers claim. Pretransition counters are collected but hook CPU is explicitly unmeasured. Earlier fallback census can perturb the later limit timing. Hashing introduces bounded per-feed work; no overall overhead estimate is claimed.

The private filter retains first_transition_* plus case, selection, bank build/admission/retirement, profile/refusal/reclaim events and trace begin/footer. Other hot trace records are suppressed before attempted-sequence allocation. Existing trace queue/footer/seal limits remain unchanged; emit waits at queue>128 for at most2s and records incomplete status on failure. Root must check strict closure/zero drops and preserve original functional failure independently.
