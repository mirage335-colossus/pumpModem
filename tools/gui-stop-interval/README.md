The primary metric is accounted stop-critical-path wall time, paired with the actual executing thread CPU and generated/traversed source/endpoint counters. Read event times within the target serial from `fixture_request` through `fixture_result`; events during subsequent exception teardown are cleanup. | Branch | Supporting observation | Restricting observation | Cheapest measurement |
