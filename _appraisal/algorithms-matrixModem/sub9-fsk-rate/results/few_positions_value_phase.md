# Sub-9 kHz FSK rate and spacing: keyed 10-bit block on a ladder of coherent windows

Generated by `coherent_block_mc.cpp`, 2000 blocks per row. Every format lasts 5,242.88 s (87.4 min) and
carries the same energy. Entries are the block E/N0 in dB at which 1% of blocks decode to a wrong
message, for the receiver that adds coherent windows of the stated length as energies. `>` marks a
rung that does not reach 1% by 44 dB. Reference: 1,024 exactly orthogonal codewords, coherent with
one unknown phase, need 12.87 dB. Known timing and frequency, Gaussian noise. Theoretical (Monte Carlo).
Value-dependent phase: the keyed map sends each of the 256 values to a position and one of four quarter
turns (the next two bits of the keyed permutation), so two messages on the same position differ in
phase three times in four. Per-tone and sub-tone rungs do not see the phase.
