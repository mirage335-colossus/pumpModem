## 7. Margin against erasures with a fixed branch count

A design closes exactly (eps = 1e-3) with L0 branches at branch SNR g0 (no margin). The link is then
operated X dB stronger on every surviving branch, and a known set of branches is erased. Entries are the
largest erased fraction 1 - L'/L0 that still meets eps, L' being the smallest surviving count that does.
`ideal` is 1 - 10^(-X/10), which holds when every look counts linearly in energy; `quad` is
1 - 10^(-2X/10), the weak-look limit in which information per look grows as the square of its SNR.

## 8. Quiet-slot (end-of-message) test with the maximum codeword score

One calendar slot carries one k-bit orthogonal section over L Rayleigh branches. The receiver declares the
slot occupied when the largest of the 2^k codeword scores exceeds a threshold. `false continuation` is
the probability that a noise-only slot is declared occupied; `false termination` is the probability that
an occupied slot is declared quiet (its own codeword score falls below the threshold; a decoding error
is counted separately). L and the no-margin branch SNR are the section-2 optimum for eps = 1e-3; X is the
margin by which every branch is stronger. k = 0 is a known keyed pattern (one hypothesis) with the same
L and branch SNR as the k = 10 design.
