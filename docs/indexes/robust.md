# Robust modem

See [current Robust architecture and status](../robust-current.md) for the
canonical native waveform/channel/Helper path, sequential Python receiver
stages, and GUI limitation. Concise historical technique findings remain in
[pattern research](../triad-patterns.md), [stochastic channel analysis](../triad-stochastic.md),
[rate-aware shaping](../triad-shaping.md), and the [shared channel contract](../channel-models.md).
The [matched pattern](../validation-data/triad-v3/2026-11-06-independent-patterns/README.md),
[spacing](../validation-data/triad-v3/2026-11-06-spacing/README.md), and
[stochastic](../validation-data/triad-v3/2026-11-05-stochastic/README.md) records
are historical evidence with source and coverage limits; they do not qualify the
current receiver.

Computationally intensive checks use the predeclared, hierarchical minimal-cost
statistical method in [the current testing policy](../robust-current.md#testing-computationally-intensive-robust-changes)
and [triad performance guidance](../triad-performance.md). Retired single-carrier
and standalone receiver recipes are not current guidance.
