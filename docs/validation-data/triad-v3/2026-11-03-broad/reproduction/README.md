# Frozen broad physical diagnostics

This page is a historical scope summary, not an experiment recipe. The [broad study report](../README.md), its [acquisition findings](../acquisition/README.md), and the [later configuration extension](../../2026-11-03-extension/README.md) retain results and assumptions. Use the current [abbreviated triad harness](../../../../triad-performance.md), [Robust testing policy](../../../../robust-current.md#testing-computationally-intensive-robust-changes), and [material lifecycle policy](../../../../development.md#material-lifecycle) for future work.

The frozen study selected configurations from 78 proposals, preserving unsupported topologies, native rejections, exclusions, numerical failures and timeouts as explicit outcomes. Its configuration census and stage counts are algebraic/planned coverage, not transmissions or successful receptions. Sampled reception and timing-bank results are available in the parent report; its reused C/N₀ noise and paired methods do not add independent physical paths or qualify operational reliability.

Transferable constraints include distinguishing configuration validity, capture feasibility, complete acquisition coverage and correct admission; counting failed and unstarted work transparently; using explicit receiver priors rather than hidden simulator truth; and measuring actual retained samples/energy for erasures. The study's nominal arrival/timing bank does not search the full physical uncertainty. Stable-ray synthetic and FHSS envelope results do not validate general channel tracking or RF retune behavior. The linked extension supersedes specific implementation limitations, while these dated measurements remain historical evidence only.
