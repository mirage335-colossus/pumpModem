# Selective-channel correction campaign record

This page records the historical model comparison; it is not a campaign planner or replay guide. The [main study](../README.md), [operator theory](../theory/README.md), and [measured response probe](../response-v2/README.md) preserve the detailed findings and provenance. New intensive Robust checks must follow the maintained [abbreviated triad harness](../../../../triad-performance.md), [computational testing policy](../../../../robust-current.md#testing-computationally-intensive-robust-changes), and [material lifecycle policy](../../../../development.md#material-lifecycle).

The study found that the legacy narrow crossover bank could collapse to nearly common modulation for displaced spectra: the adjacent complex gain-difference RMS in the documented Each65 case fell from 0.8501 at zero offset to 0.0001798 at a +0.05 Hz offset, although per-tone amplitude modulation remained. The corrected dispersive DFT-delay operator addresses that spectral-placement problem in the isolated v3 stream. It is a synthetic frequency-selectivity stress law at the tested scale, with branch delays approaching 889 seconds; it should not be interpreted as evidence that ordinary short-delay channels create strong differential response across 0.00075 Hz-separated carriers. For a 5 ms excess delay, the inter-carrier phase difference is only about 2.36e-5 radians.

The paired development/holdout and timing-oracle results are in the main study. The tone probe and operator response establish model behavior, not receiver qualification. Broad sensitivity boundaries and operational reliability remain unqualified. The isolated stream's corrected model does not change ordinary Robust defaults or hardware paths.
