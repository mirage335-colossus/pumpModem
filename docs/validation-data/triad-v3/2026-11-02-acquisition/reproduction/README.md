# Acquisition study record

This is a concise record of historical algorithm findings, not a reproduction or test checklist. The [study report](../README.md) preserves model definitions, campaign outcomes, exact-Gaussian classification analysis and evidence provenance. For new intensive Robust checks, use the maintained [abbreviated triad harness](../../../../triad-performance.md), [computational testing policy](../../../../robust-current.md#testing-computationally-intensive-robust-changes), and [material lifecycle policy](../../../../development.md#material-lifecycle).

The actual-observation grouped acquisition path addressed a concrete failure where nominal timing could confidently choose the wrong bit although a nearby public timing hypothesis supported the transmitted waveform. In the completed campaign, major timing failures were reduced, but all eight wrong-key controls were admitted at both gates and null admissions were 0/8. An experimental consistency postprocessor rejected the reused and fresh wrong-key controls but also removed one of 16 fresh legitimate receptions. It remains an unselected research result, and the campaign does not establish key authentication or operational admission reliability.

A separate analysis bounded the 99%-correct classification cost of the tested block-16 point to within 1 dB of the exact reference's required C/N₀ for the stated 0.125-second known-synchronization Gaussian model. It did not locate the minimum crossing or establish a finite-acquisition/admission gap, and excludes wrong keys and the finite Each65 channel law. The 2–3 dB finite-acquisition goal remains unresolved. Keep aligned classification bounds, finite-bank acquisition, and complete receiver admission claims separate; a bound from a simpler model cannot stand in for the full receiver.

Archived source and run identities describe the historical implementation and inputs; they are not current build dependencies. The ordinary Robust receiver was not changed or qualified by this study.
