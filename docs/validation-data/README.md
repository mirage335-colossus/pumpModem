# Retained development inputs

This directory keeps selected receiver evidence for unfinished work and the
Bookworm offline-build baseline. Active regression fixtures live under `tests/`.
These records retain measurements and their available source provenance, not
current qualification or instructions to reproduce an old development
environment. Provenance completeness is stated by each record.

[Helper Carrier evidence](helper/README.md) preserves selected standalone
frequency, phase, timing and complete-stream results, including failed cases,
public fixture keys, exact commands and a portable checker. Its
[integration guide](../helper-integration.md) identifies implemented approaches
and the authoritative transmission format without requiring one receiver design.

Completed Fast studies and other superseded captures are available in
[Git history](https://github.com/mirage335-colossus/pumpModem/tree/5b343de5ac5a3e33ac404b796c9ade0ba90d9409/docs/validation-data), rather than copied or
compressed again here. See [current validation](../validation.md),
[future prompts](../../FURTHER-agents.txt) and [evidence navigation](../indexes/evidence.md).
